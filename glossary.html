📖 Spark the Circuit - Technical Glossary

Comprehensive professional definitions for 50 essential hardware, communication protocol, register, and firmware engineering terminologies.

1. GPIO (General Purpose Input/Output)

Pins on an integrated circuit or microcontroller that can be configured via software to act as digital input lines to read sensors or digital output lines to control LEDs, relays, and actuators.

2. PWM (Pulse Width Modulation)

A modulation technique used to encode specific amplitude information into a pulsed digital signal, frequently utilized for dimming LEDs, controlling servo motor angles, and regulating DC motor speeds.

3. UART (Universal Asynchronous Receiver-Transmitter)

A hardware communication protocol utilizing asynchronous serial data transmission over two dedicated signal lines (TX for transmission and RX for receiving) without a shared clock signal.

4. SPI (Serial Peripheral Interface)

A synchronous serial communication bus specification engineered for high-speed, short-distance data exchange between microcontrollers and peripheral ICs using master-slave architecture.

5. I2C (Inter-Integrated Circuit)

A synchronous multi-master, multi-slave packet-switched single-ended serial communication bus utilizing only two lines: Serial Data (SDA) and Serial Clock (SCL).

6. ADC (Analog-to-Digital Converter)

An electronic integrated circuit that samples continuous analog voltage signals and converts them into discrete digital numbers that microcontrollers can process mathematically.

7. DAC (Digital-to-Analog Converter)

A system that translates digital binary codes into continuous analog voltage or current signals, enabling true audio wave synthesis and precise analog control voltages.

8. DMA (Direct Memory Access)

A hardware feature allowing peripheral subsystems to transfer data directly to and from system RAM independently of the central processing unit, maximizing execution efficiency.

9. ISR (Interrupt Service Routine)

A specialized software callback function executed by microcontroller firmware immediately upon receiving a hardware or software interrupt signal, pausing main loop execution temporarily.

10. Firmware

Low-level persistent software stored in non-volatile flash memory that provides direct hardware control, initialization routines, and operating logic for specific electronic devices.

11. Bootloader

A small snippet of code stored in protected boot memory that executes upon system startup, responsible for initializing hardware and loading application firmware via USB or serial.

12. Pull-up Resistor

A resistor connected between a signal line and the positive supply voltage to ensure the line defaults to a defined HIGH logic state when no active driver pulls it LOW.

13. Pull-down Resistor

A resistor connected between a signal line and ground to ensure the line defaults to a stable LOW logic state, preventing floating inputs on digital pins.

14. Watchdog Timer (WDT)

An electronic hardware timer that automatically generates a system reset if the main program freezes or fails to reset the timer periodically due to software hangs.

15. EEPROM

Electrically Erasable Programmable Read-Only Memory. Non-volatile memory storage utilized by microcontrollers to retain calibration constants and user settings when powered off.

16. Flash Memory

Non-volatile computer memory capable of being electrically erased and reprogrammed in blocks, primarily used for storing compiled microcontroller firmware programs.

17. SRAM (Static Random-Access Memory)

Fast volatile semiconductor memory used to store active variable states, stack frames, and dynamic buffers during program execution.

18. Registers

Small, ultra-fast storage locations built directly inside the CPU core used to hold immediate data, memory addresses, and hardware configuration flags.

19. Multiplexer (MUX)

A combinational logic circuit that selects one of several analog or digital input signals and forwards the selected input into a single output line.

20. Decoupling Capacitor

A capacitor placed across power supply pins close to integrated circuits to suppress high-frequency voltage noise and stabilize transient current demands.

21. Optocoupler

An electronic component that transfers electrical signals between two isolated circuits using light waves, protecting sensitive microcontrollers from high-voltage spikes.

22. Crystal Oscillator

An electronic oscillator circuit that uses the mechanical resonance of a piezoelectric vibrating crystal of quartz to create an electrical signal with a precise clock frequency.

23. Logic Level Shifter

An active electronic circuit or module that safely translates digital signals operating at different voltages (e.g., converting 3.3V signals to 5V logic).

24. H-Bridge

An electronic circuit configuration utilizing four switching elements that enables DC electric motors to run in both forward and reverse directions.

25. Schmitt Trigger

A comparator circuit with hysteresis that converts noisy, slow-transition input waveforms into clean, sharp digital square waves.

26. Step-Down (Buck) Converter

A DC-to-DC power converter that steps down voltage from a higher DC input to a lower DC output with high energy conversion efficiency.

27. LDO (Low-Dropout Regulator)

A DC linear voltage regulator that can regulate the output voltage even when the supply voltage is very close to the output voltage.

28. Open Drain / Open Collector

An output stage configuration where the pin connects to ground through a transistor switch, requiring an external pull-up resistor to reach HIGH logic.

29. Push-Pull Output

A totem-pole output stage utilizing complementary transistors that actively drive output lines to both HIGH and LOW voltage rails.

30. JTAG

Joint Test Action Group. An industry standard protocol used for verifying board designs and testing integrated circuits via dedicated boundary-scan pins.

31. SWD (Serial Wire Debug)

A two-pin electrical alternative to JTAG used by ARM Cortex microcontrollers for debugging and firmware flashing.

32. CAN Bus

Controller Area Network. A robust vehicle bus standard designed to allow microcontrollers and devices to communicate with each other without a host computer.

33. RS-485

A differential serial communication standard used for long-distance, high-noise industrial data transmission over twisted-pair cables.

34. USB HID (Human Interface Device)

A device class definition for USB protocols that enables keyboards, mice, and custom macro pads to interact with host computers natively.

35. BLE (Bluetooth Low Energy)

A wireless personal area network technology designed for ultra-low power consumption in short-range IoT sensor deployments.

36. Wi-Fi Stack

A collection of networking protocols and TCP/IP software drivers enabling microcontrollers to connect to wireless routers and web servers.

37. MQTT

Message Queuing Telemetry Transport. An extremely lightweight publish-subscribe network protocol designed for constrained IoT devices.

38. OTA (Over-The-Air) Updates

The wireless method of distributing and installing new firmware versions to connected IoT microcontrollers via Wi-Fi networks.

39. RTOS (Real-Time Operating System)

An operating system intended to serve real-time application process requests with guaranteed predictable timing constraints.

40. Multitasking

The execution of multiple concurrent software tasks or threads managed by scheduling algorithms within microcontroller firmware.

41. Polling

A programming technique where the CPU continuously monitors the status of a peripheral or sensor in a tight loop to detect events.

42. Interrupt Latency

The time elapsed interval between the generation of an interrupt event and the execution of the first instruction in its corresponding ISR.

43. Contact Debouncing

The process of filtering out electrical contact bouncing noise generated by mechanical push buttons using hardware RC filters or software delay loops.

44. PCB (Printed Circuit Board)

A laminated non-conductive mechanical substrate with copper tracks and pads etched to electrically connect electronic components.

45. SMD (Surface-Mount Device)

Electronic components designed to be mounted directly onto the surface of a printed circuit board rather than through pre-drilled holes.

46. Impedance

The total measure of opposition that a circuit presents to alternating current consisting of resistance, inductive reactance, and capacitive reactance.

47. Baud Rate

The rate at which information is transferred in a communication channel, measured in symbols or pulses per second (e.g., 9600 baud).

48. Schematic Diagram

A technical blueprint drawing that represents the electrical connections and component symbols of an electronic circuit.

49. Breadboard

A solderless construction base used for building temporary electronic prototypes and testing experimental circuit designs.

50. Soldering

The process of joining different metal pieces together by melting filler metal (solder) into the joint at elevated temperatures.
