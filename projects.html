1. Obstacle Avoiding Smart Robot

An autonomous robot chassis that sweeps an ultrasonic distance sensor using a servo motor to detect obstacles and steer away using DC gear motors.

📦 Components Required:

  • 1x Arduino Uno R3
  • 1x L298N Motor Driver Module
  • 1x HC-SR04 Ultrasonic Sensor
  • 1x SG90 Servo Motor
  • 1x 2WD Robot Smart Chassis with DC Motors
  • 2x 18650 Li-ion Batteries & Holder

🔌 Wiring Instructions:

  • HC-SR04 Trig Pin to Arduino Digital Pin 9, Echo Pin to Digital Pin 8, VCC to 5V, GND to GND.
  • L298N Motor Driver Inputs: IN1 to Pin 4, IN2 to Pin 5, IN3 to Pin 6, IN4 to Pin 7.
  • SG90 Servo Control Signal to Pin 10, VCC to 5V, GND to GND.

📋 Step-by-Step Procedure:

  1. Assemble the 2WD robot chassis and mount the DC motors and wheels.
  2. Mount the L298N motor driver, Arduino board, and battery holder to the top chassis.
  3. Attach the SG90 servo motor to the front chassis and mount the HC-SR04 sensor on top of the servo horn.
  4. Connect all signal wires according to the wiring list and upload the code.

💻 Complete Source Code:

#include <Servo.h>
Servo headServo;
const int trigPin = 9;
const int echoPin = 8;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(4, OUTPUT); pinMode(5, OUTPUT);
  pinMode(6, OUTPUT); pinMode(7, OUTPUT);
  headServo.attach(10);
  headServo.write(90);
}

long getDistance() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  long duration = pulseIn(echoPin, HIGH);
  return duration * 0.034 / 2;
}

void loop() {
  long dist = getDistance();
  if (dist > 20) {
    digitalWrite(4, HIGH); digitalWrite(5, LOW);
    digitalWrite(6, HIGH); digitalWrite(7, LOW);
  } else {
    digitalWrite(4, LOW); digitalWrite(5, LOW);
    digitalWrite(6, LOW); digitalWrite(7, LOW);
    delay(300);
    digitalWrite(4, LOW); digitalWrite(5, HIGH);
    digitalWrite(6, LOW); digitalWrite(7, HIGH);
    delay(500);
  }
}

2. Automated Smart Irrigation System

Monitors soil moisture level using a resistive sensor probe and automatically activates a mini water pump through a relay when the soil becomes dry.

📦 Components Required:

  • 1x Arduino Nano or Uno
  • 1x Soil Moisture Sensor Probe & Module
  • 1x 5V Single Channel Relay Module
  • 1x 3-6V Mini Submersible Water Pump & Tubing
  • 1x 5V Power Supply / Battery Pack

🔌 Wiring Instructions:

  • Soil Moisture Analog Output (AO) to Arduino Pin A0, VCC to 5V, GND to GND.
  • Relay Module IN Pin to Arduino Digital Pin 7, VCC to 5V, GND to GND.
  • Water pump power connected in series through the Relay Normally Open (NO) and Common (COM) contacts.

📋 Step-by-Step Procedure:

  1. Insert the soil moisture sensor prongs into a pot filled with soil.
  2. Connect the water pump tubing to a water container and direct the output tube to the plant root.
  3. Wire the relay module between the external pump power supply and the pump terminals.
  4. Upload the Arduino sketch and calibrate dryness thresholds in code.

💻 Complete Source Code:

const int sensorPin = A0;
const int relayPin = 7;
int threshold = 500;

void setup() {
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, HIGH);
  Serial.begin(9600);
}

void loop() {
  int sensorValue = analogRead(sensorPin);
  Serial.print("Soil Moisture Level: ");
  Serial.println(sensorValue);
  
  if (sensorValue > threshold) {
    digitalWrite(relayPin, LOW); // Pump ON
  } else {
    digitalWrite(relayPin, HIGH); // Pump OFF
  }
  delay(2000);
}

3. Bluetooth Home Automation Controller

Allows users to toggle household electrical loads wirelessly using a mobile phone via an HC-05 Bluetooth transceiver module.

📦 Components Required:

  • 1x Arduino Uno
  • 1x HC-05 Bluetooth Module
  • 1x 4-Channel 5V Relay Module
  • Connecting Jumper Wires

🔌 Wiring Instructions:

  • HC-05 TX to Arduino RX (Pin 0), HC-05 RX to Arduino TX (Pin 1 through a voltage divider), VCC to 5V, GND to GND.
  • Relay Module IN1, IN2, IN3, IN4 to Arduino Pins 2, 3, 4, 5.

📋 Step-by-Step Procedure:

  1. Disconnect TX/RX lines while uploading code to avoid serial port conflict.
  2. Pair smartphone with HC-05 Bluetooth module (default PIN: 1234 or 0000).
  3. Use a Bluetooth terminal app to send serial commands '1', '2', '3', '4' to switch relays.

💻 Complete Source Code:

char state = 0;

void setup() {
  Serial.begin(9600);
  for(int i = 2; i <= 5; i++) {
    pinMode(i, OUTPUT);
    digitalWrite(i, HIGH);
  }
}

void loop() {
  if (Serial.available() > 0) {
    state = Serial.read();
    if (state == '1') digitalWrite(2, !digitalRead(2));
    if (state == '2') digitalWrite(3, !digitalRead(3));
    if (state == '3') digitalWrite(4, !digitalRead(4));
    if (state == '4') digitalWrite(5, !digitalRead(5));
  }
}

4. IoT Weather Station (ESP32)

Reads temperature and humidity readings from a DHT11 sensor and prints environmental telemetry data over the serial monitor and local network.

📦 Components Required:

  • 1x ESP32 Development Board
  • 1x DHT11 Temperature & Humidity Sensor
  • 1x 10k Ohm Resistor
  • Breadboard & Jumper Wires

🔌 Wiring Instructions:

  • DHT11 VCC to 3.3V on ESP32, GND to GND.
  • DHT11 Data Pin to ESP32 GPIO 4 with a 10k resistor pull-up to 3.3V.

📋 Step-by-Step Procedure:

  1. Install DHT sensor library in Arduino IDE.
  2. Connect ESP32 via Micro-USB cable.
  3. Compile and upload sketch; open Serial Monitor at 115200 baud to view real-time data logs.

💻 Complete Source Code:

#include "DHT.h"
#define DHTPIN 4
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);
  dht.begin();
}

void loop() {
  delay(2000);
  float h = dht.readHumidity();
  float t = dht.readTemperature();
  
  if (isnan(h) || isnan(t)) {
    Serial.println("Failed to read from DHT sensor!");
    return;
  }
  
  Serial.print("Humidity: "); Serial.print(h); Serial.print("% ");
  Serial.print("Temperature: "); Serial.print(t); Serial.println("°C");
}

5. Smart Line Follower Robot

A mobile robot that uses two reflective optical IR sensors to stay aligned on a black electrical tape line.

📦 Components Required:

  • 1x Arduino Nano
  • 2x IR Reflective Line Sensors
  • 1x L298N Motor Driver
  • 1x Robot Chassis with 2 DC Motors

🔌 Wiring Instructions:

  • Left IR Sensor OUT to Pin A0, Right IR Sensor OUT to Pin A1.
  • Motor Driver IN1 to Pin 5, IN2 to Pin 6, IN3 to Pin 9, IN4 to Pin 10.

📋 Step-by-Step Procedure:

  1. Mount IR sensors underneath the front bumper facing down (1-2 cm above surface).
  2. Create a track on a white poster board using black insulation tape.
  3. Adjust sensitivity trimpots on IR modules until black tape is reliably detected.

💻 Complete Source Code:

const int leftIR = A0;
const int rightIR = A1;

void setup() {
  pinMode(leftIR, INPUT);
  pinMode(rightIR, INPUT);
  for(int i = 5; i <= 10; i++) pinMode(i, OUTPUT);
}

void loop() {
  int leftVal = digitalRead(leftIR);
  int rightVal = digitalRead(rightIR);

  if (leftVal == LOW && rightVal == LOW) { // Forward
    digitalWrite(5, HIGH); digitalWrite(6, LOW);
    digitalWrite(9, HIGH); digitalWrite(10, LOW);
  } else if (leftVal == HIGH && rightVal == LOW) { // Turn Left
    digitalWrite(5, LOW); digitalWrite(6, LOW);
    digitalWrite(9, HIGH); digitalWrite(10, LOW);
  } else if (leftVal == LOW && rightVal == HIGH) { // Turn Right
    digitalWrite(5, HIGH); digitalWrite(6, LOW);
    digitalWrite(9, LOW); digitalWrite(10, LOW);
  } else { // Stop
    digitalWrite(5, LOW); digitalWrite(6, LOW);
    digitalWrite(9, LOW); digitalWrite(10, LOW);
  }
}

6. RFID Access Control Lock

Scans RFID cards and keyfobs using an RC522 reader to unlock an electronic solenoid door latch upon valid authorization.

📦 Components Required:

  • 1x Arduino Uno
  • 1x MFRC522 RFID Module
  • 1x 5V Relay Module & 12V Solenoid Lock
  • 1x Green LED, 1x Red LED, 2x 220Ω Resistors

🔌 Wiring Instructions:

  • RC522 SPI: SDA to Pin 10, SCK to Pin 13, MOSI to Pin 11, MISO to Pin 12, RST to Pin 9, 3.3V to 3.3V.
  • Relay IN to Pin 7, Green LED to Pin 4, Red LED to Pin 5.

📋 Step-by-Step Procedure:

  1. Wire the SPI pins of the RC522 module to the Arduino board.
  2. Upload the code and open the Serial Monitor to capture your master RFID card UID code.
  3. Replace the master UID string in the code with your card code and re-upload.

💻 Complete Source Code:

#include <SPI.h>
#include <MFRC522.h>

#define SS_PIN 10
#define RST_PIN 9
MFRC522 rfid(SS_PIN, RST_PIN);

void setup() {
  Serial.begin(9600);
  SPI.begin();
  rfid.PCD_Init();
  pinMode(7, OUTPUT); digitalWrite(7, HIGH);
  pinMode(4, OUTPUT); pinMode(5, OUTPUT);
}

void loop() {
  if (!rfid.PICC_IsNewCardPresent() || !rfid.PICC_ReadCardSerial()) return;
  
  digitalWrite(4, HIGH);
  digitalWrite(7, LOW); // Unlock
  delay(3000);
  digitalWrite(7, HIGH); // Lock
  digitalWrite(4, LOW);
  rfid.PICC_HaltA();
}

const int flamePin = 2;
const int buzzerPin = 8;
const int ledPin = 13;

void setup() {
  pinMode(flamePin, INPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(ledPin, OUTPUT);

🔌 Wiring Instructions:

  • I2C LCD SDA to Pin A4, SCL to Pin A5, VCC to 5V, GND to GND.

📋 Step-by-Step Procedure:

  1. Attach the I2C module directly to the 16x2 LCD header.
  2. Connect SDA and SCL to Arduino analog pins A4 and A5.
  3. Upload the code to view live distance readouts updated every 250 milliseconds.

💻 Complete Source Code:

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);
const int trigPin = 9;
const int echoPin = 8;

void setup() {
  lcd.init(); lcd.backlight();
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}

void loop() {
  digitalWrite(trigPin, LOW); delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  long duration = pulseIn(echoPin, HIGH);
  int distance = duration * 0.034 / 2;
  
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Distance Meas:");
  lcd.setCursor(0, 1);
  lcd.print(distance); lcd.print(" cm");
  delay(250);
}

9. Dual-Axis Solar Tracker System

Uses four LDR light sensors and two servo motors to continuously point a solar panel towards the brightest light source.

📦 Components Required:

  • 1x Arduino Uno
  • 4x LDR Light Sensors & 4x 10kΩ Resistors
  • 2x SG90 Servo Motors
  • 1x Solar Panel Model Frame

🔌 Wiring Instructions:

  • LDR Dividers to Pins A0 (Top-Left), A1 (Top-Right), A2 (Bottom-Left), A3 (Bottom-Right).
  • Horizontal Servo Signal to Pin 9, Vertical Servo Signal to Pin 10.

📋 Step-by-Step Procedure:

  1. Build a pan-tilt servo bracket holding the miniature solar panel and 4 LDRs in a grid.
  2. Connect servo power leads to external 5V power supply to handle motor stall currents.
  3. Run code and shine a flashlight across panel to test auto-tracking alignment.

💻 Complete Source Code:

#include <Servo.h>
Servo horizontal; Servo vertical;
int servoh = 90; int servov = 90;

void setup() {
  horizontal.attach(9); vertical.attach(10);
  horizontal.write(servoh); vertical.write(servov);
}

void loop() {
  int tl = analogRead(A0); int tr = analogRead(A1);
  int bl = analogRead(A2); int br = analogRead(A3);
  
  int avt = (tl + tr) / 2; int avd = (bl + br) / 2;
  int avl = (tl + bl) / 2; int avr = (tr + br) / 2;
  
  if (avt < avd && servov < 180) servov++;
  else if (avd < avt && servov > 0) servov--;
  vertical.write(servov);
  
  if (avl < avr && servoh < 180) servoh++;
  else if (avr < avl && servoh > 0) servoh--;
  horizontal.write(servoh);
  delay(50);
}

10. Touchless Smart Trash Can

Automatically opens a dustbin lid using a servo motor when a hand approaches within 15 cm of the ultrasonic sensor.

📦 Components Required:

  • 1x Arduino Uno or Nano
  • 1x HC-SR04 Ultrasonic Sensor
  • 1x SG90 Micro Servo Motor
  • 1x Small Trash Can with Hinged Lid

🔌 Wiring Instructions:

  • HC-SR04 Trig to Pin 6, Echo to Pin 5, VCC to 5V, GND to GND.
  • SG90 Servo Signal to Pin 9, VCC to 5V, GND to GND.

📋 Step-by-Step Procedure:

  1. Mount HC-SR04 on the front rim of dustbin facing forward.
  2. Attach servo motor to bin lid hinge using a stiff push rod wire.
  3. Calibrate servo angle in code to open lid to 90 degrees and auto-close after 3 seconds.

💻 Complete Source Code:

#include <Servo.h>
Servo lidServo;
const int trigPin = 6;
const int echoPin = 5;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  lidServo.attach(9);
  lidServo.write(0); // Lid closed
}

void loop() {
  digitalWrite(trigPin, LOW); delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  long duration = pulseIn(echoPin, HIGH);
  int distance = duration * 0.034 / 2;
  
  if (distance > 0 && distance < 15) {
    lidServo.write(90); // Open
    delay(3000);
    lidServo.write(0);  // Close
  }
  delay(200);
}

1. Simple Transistor Touch Switch

A touch-activated switch using a dual NPN transistor Darlington pair configuration to turn on an LED when human touch bridges contacts.

📦 Components Required:

  • 2x BC547 NPN Transistors
  • 1x 220Ω Resistor
  • 1x 100kΩ Resistor
  • 1x Red LED
  • 1x 9V Battery & Snap Connector
  • 1x Solderless Breadboard & Touch Wires

🔌 Circuit Wiring Instructions:

  • Connect 9V Positive rail to LED Anode through a 220Ω current limiting resistor.
  • Connect LED Cathode to Collector of Transistor 2.
  • Connect Emitter of Transistor 1 directly to Base of Transistor 2 (Darlington Pair Configuration).
  • Connect Emitter of Transistor 2 to 9V Ground rail.
  • Connect 100kΩ resistor from 9V Positive rail to Touch Pin A. Connect Base of Transistor 1 to Touch Pin B.

📋 Step-by-Step Assembly Procedure:

  1. Insert both BC547 transistors onto breadboard facing flat sides forward.
  2. Form Darlington pair by jumping Emitter 1 to Base 2.
  3. Bridge touch wires; placing a finger across them passes microamp current to illuminate the LED.
